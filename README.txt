SAVANNA BREW CAFE WEBSITE
HTML AND CSS ASSIGNMENT

PROJECT DESCRIPTION
Savanna Brew Cafe is a responsive café website developed using HTML5 and CSS3. It provides information about the café, its menu, photo gallery, contact details and reservation form.

PROJECT PAGES
1. index.html - Home page
2. about.html - About the café
3. menu.html - Café menu and prices
4. gallery.html - Café image gallery
5. contact.html - Contact information, location map and reservation form

TECHNOLOGIES USED
- HTML5
- CSS3
- Google Fonts
- Google Maps embedded map
- External social media icons

VALIDATION
- All five HTML files were checked using the W3C HTML Validator.
- The CSS file (css/style.css) was checked using the W3C CSS Validator.
- No validation errors were reported.

NOTES
- The website uses a responsive layout for desktop, tablet and mobile screens.
- The reservation form is a front-end demonstration and does not store or transmit submitted reservations because no backend has been implemented.
